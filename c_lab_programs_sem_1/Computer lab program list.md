# Computer Lab Program list

## Unit 1

- [ ] 1 - Write a program in C to input length and breadth of a rectangle and find the area of the rectangle.
- [ ] 2 - Write a program in C to find the area of a circle, given the radius.
- [ ] 3 - Write a program in C to find the area of a triangle given the lengths of three sides.
- [ ] 4 - Write a program in C to convert temp in Celsius scale to Fahrenheit scale.
- [ ] 5 - Write a program in C to find the distance travelled by an object moving with a velocity U and acceleration a in time t.
- [ ] 6 - Write a program in C to find the area of a triangle given the lengths of base and height.
- [ ] 7 - Write a program in C to input 5 numbers and find the sum and average of those numbers.
- [ ] 8 - Write a program in C to input 5 numbers and find the standard deviation of those five numbers.
- [ ] 9 - Write a program in C to find the volume of a sphere of radius R.
- [ ] 10 - Write a program in C to find the area not covered by a circle touching the sides of a square of radius R.
- [ ] 11 - Write a program in C to find the distance between two points P1(x1,y1) and P2(x2,y2).
- [ ] 12 - Input principal, rate, and time from the user. Compute simple interest.
- [ ] 13 - Calculate Perimeter of a Rectangle.
- [ ] 14 - Calculate the Surface Area of a Cylinder.
- [ ] 15 - Convert Days to Weeks and Days.
- [ ] 16 - Write a program in C to find the cosine of an angle in degrees by summing the first 5 terms of the cosine series.
